# P1-D2: Approved artifact lifecycle

## Summary
Treat approved review outputs as first-class preferred artifacts with deterministic generate behavior.

## Acceptance criteria
- [ ] Approved subtitle artifacts are explicitly registered as preferred outputs.
- [ ] Generate mode checks preferred approved artifact and reports deterministic selection behavior.
- [ ] Parent/child lineage between original and approved candidate is persisted.
- [ ] Re-approval flow is supported and tested.
