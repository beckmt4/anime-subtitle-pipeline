# P0-C1: Ship reference default OCR backend

## Summary
Promote OCR from bring-your-own plugin to a documented, supported default local backend.

## Acceptance criteria
- [ ] A default OCR backend is selected, implemented, and documented.
- [ ] OCR enablement/disablement behavior is explicit in generate/benchmark logs.
- [ ] When OCR is enabled but backend dependencies are missing, error messaging is clear and actionable.
- [ ] README/docs include setup instructions and expected limitations.
