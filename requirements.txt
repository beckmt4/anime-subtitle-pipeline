# ============================================================================
# GPU Support Notes:
# ============================================================================
# For CUDA GPU support:
#   1. Install NVIDIA CUDA Toolkit (11.8 or 12.1 recommended)
#   2. Install PyTorch 2.6+ with CUDA support BEFORE running pip install -r requirements.txt:
#      pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu118
#      (Replace cu118 with your CUDA version, e.g., cu121 for CUDA 12.1)
#   3. Then install other requirements:
#      pip install -r requirements.txt
#
# For CPU-only (no GPU):
#   pip install torch>=2.6.0
#   pip install -r requirements.txt
