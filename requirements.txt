# Core dependencies
pyyaml>=6.0

# ASR - Faster-Whisper with CTranslate2

# Machine Translation - Hugging Face Transformers

# ============================================================================
# GPU Support Notes:
# ============================================================================
# Tested configuration: NVIDIA RTX 4090, driver 580.142, CUDA 13.0, torch 2.11.0+cu130
#
# For CUDA GPU support:
#   1. Install PyTorch with CUDA support BEFORE running pip install -r requirements.txt:
#      pip install torch --index-url https://download.pytorch.org/whl/cu128
#      (cu128 = CUDA 12.8, the latest stable wheel; use cu121 for CUDA 12.1)
#   2. Then install other requirements:
#      pip install -r requirements.txt
#   Note: nvidia-cublas-cu12 is included above — it is REQUIRED even on CUDA 13 installs
#         because CTranslate2/faster-whisper lazy-loads libcublas.so.12 at runtime.
#
# For CPU-only (no GPU):
#   pip install torch>=2.6.0
#   pip install -r requirements.txt
